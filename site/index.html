Two things that shouldn't be hard

Your SSH setup works in Terminal, then breaks in your file manager.

Keys in your agent, hosts in ~/.ssh/config, a jump host in between. Terminal handles all of it. Then the file manager asks for a key file it should already know about, or sits on “connecting…”.

Keyboard-first file managers stopped being keyboard-first.

Marking files with the Space bar and working with the F-keys of the classic commanders is how many people move files. On the Mac it has been disappearing.

How it works

  1. Open Shellpane.

    The hosts in your ~/.ssh/config are already in the sidebar.

  2. Click one.

    Shellpane runs your Mac's own ssh, the same program Terminal uses, so it logs in the same way.

  3. Work from the keyboard.

    Space marks files, F5 copies them to the other pane, F6 moves them, F4 edits one on the server.

What makes it different

It's your ssh.

Shellpane drives /usr/bin/ssh: your ~/.ssh/config with its aliases, IdentityFile, ProxyJump, Include and Match, the agent your Terminal uses, known_hosts and passphrase-protected keys.

Your shell's agent, even from the Dock.

If your shell profile points SSH_AUTH_SOCK at an agent, Shellpane reads it, so opening the app from Finder doesn't lose it.

Commander keys.

Space or Insert marks, arrows keep your marks, F3 Quick Look, F4 edit, F5 copy, F6 move, F7 new folder, F8 delete, / filters. Prefer Space for Quick Look? One switch in Settings.

Errors you can act on.

“web-1 refused the connection. Check the port, and that SSH is running on the server.” Then ssh's own words underneath, and a button that copies the same login as an ssh -v command for Terminal.

A changed server identity stops everything.

First contact shows the fingerprint. If a server's key ever changes, Shellpane refuses to connect. There is no “connect anyway” button.

And everything you'd expect

  • Two panes, tabs, list, icon and column views, back and forward
  • Copy and move between Mac and server, or server and server, by keys, drag and drop or ⌘C ⌘V
  • A transfer queue you can pause, reorder and retry
  • Folder sync with a preview of every add, update and delete before anything happens
  • Edit a server file in your own editor. Each save uploads, and Shellpane won't overwrite a copy someone else changed meanwhile
  • Open in Terminal, iTerm, Ghostty or Warp at the folder you're in
  • Saved servers in groups, passwords and passphrases in your Keychain
  • File info and permissions, an operation log, bandwidth limits
  • Export and import your server list

Questions

Why isn't it in the Mac App Store?

App Store apps are sandboxed, and a sandboxed app can't run your Mac's ssh or read ~/.ssh. Being your ssh is the point of Shellpane, so it's distributed directly, from GitHub.

Does it work with the 1Password or Secretive SSH agent?

Shellpane runs the same ssh as Terminal, with your config and your shell's SSH_AUTH_SOCK. If an agent works with ssh in Terminal, Shellpane uses it the same way.

Jump hosts, bastions, ProxyJump?

Yes, through your ~/.ssh/config, exactly as ssh does.

Password logins?

Yes. Shellpane saves a password in your Keychain only after it has worked, and there's a switch to not save it at all.

Which servers does it work with?

Any server with SSH and SFTP: Linux, BSD, macOS, most NAS boxes. FTP, S3 and cloud drives aren't supported. Shellpane does one thing.

Does it phone home?

No analytics and no tracking. Shellpane makes no network connections other than the SSH connections you open.

Why does macOS say it can't verify Shellpane?

Until it's notarised by Apple, macOS asks the first time. Click Done, then open System Settings › Privacy & Security, scroll down and click Open Anyway. You only do this once. Or build it yourself from the source.

I'm coming from another SFTP app. Can I bring my servers?

Your ~/.ssh/config hosts appear on first launch. Other saved servers can be added once with the Connect form, and from then on you can export and import Shellpane's list between Macs.

What do I need?

macOS 14 or later, on an Apple silicon or Intel Mac.
