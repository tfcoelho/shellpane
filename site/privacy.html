Privacy

Last updated 13 October 2026.

The app collects nothing

Shellpane has no analytics, no crash reporting service, no tracking and no account. It makes no network connections other than the SSH connections you open.

What stays on your Mac

  • Your saved servers, groups and settings, in Shellpane's folder in Application Support.
  • Passwords and key passphrases you choose to save, in your macOS Keychain.
  • Server fingerprints, in ~/.ssh/known_hosts, the same file ssh uses.

None of this is sent anywhere. Export of your server list writes a file you choose, and never includes passwords.

This website

No cookies, no analytics scripts and no third-party fonts. The site and the downloads are hosted by GitHub (GitHub Pages and GitHub Releases), which keeps its own server logs under the GitHub Privacy Statement. We don't receive them.
